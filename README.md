# NEON MATRIX — 30 KPI Dashboard Models

Thư viện dashboard KPI đa lĩnh vực bằng HTML/CSS/JavaScript/SVG thuần, thiết kế **neon dark**, hoạt động **offline** và trên **GitHub Pages**.

## Tính năng
- **30 mô hình ngành**; mỗi mô hình chứa **9 biểu đồ trong ma trận 3×3**: 270 chart xuất hiện theo lựa chọn ngành.
- **17 loại biểu đồ**: line, area, bar, horizontal bar, donut, heatmap, gauge, radar, scatter, bubble, waterfall, funnel, treemap, stacked, timeline, candlestick, radial.
- Chọn ngành, tìm kiếm, lọc danh mục, bộ lọc chu kỳ/khu vực, chạy/tạm dừng mô phỏng.
- Phóng to biểu đồ, giải thích ký pháp, sao chép/xuất SVG.
- **Copy HTML**, **Xuất HTML** chỉ một ngành, hoặc xuất trang HTML đầy đủ 30 ngành; tất cả nhúng CSS, JS và SVG, **không dùng CDN**.
- Giao diện responsive cho desktop/tablet/mobile, không cần backend.

## Chạy local
Tải `index.html` và mở bằng trình duyệt. Không cần build/dependency.

## GitHub Pages
Tại **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, **main / (root)** rồi Save. Truy cập https://base27-cvnss.github.io/dashboard/ sau khi Pages được kích hoạt.

## Lưu ý dữ liệu
**Toàn bộ KPI, biểu đồ và giá trị đều là dữ liệu DEMO giả định, không phải số liệu thực tế hoặc kết luận chuyên môn.** Chế độ “Chạy mô phỏng” chỉ thay đổi dữ liệu trực quan được tạo tại trình duyệt, không kết nối máy chủ thời gian thực.
